# Flip 7 Zähler

Punkte-Zähler für das Kartenspiel Flip 7, gedacht für große Runden (bis 10+ Spieler).
Eine einzelne `index.html`, kein Build, läuft direkt im Handy-Browser.

## Nutzung

`index.html` öffnen (oder über GitHub Pages ausliefern). Spielstand wird im Browser gespeichert.

- **Runde**: pro Spieler die gezogenen Zahlenkarten und Bonuskarten antippen, oder „Bust“.
  Punkte werden automatisch berechnet (×2 gilt nur für Zahlenkarten, +Karten danach, 7 Zahlenkarten = +15).
  Alternativ Punkte manuell eintragen.
- **Tabelle**: Rangliste mit Fortschritt bis zum Ziel (Standard 200). Bei Erreichen wird der Gewinner angezeigt.
- **Verlauf**: alle Runden als Tabelle, letzte Runde zurücknehmen, neues Spiel starten.

Der Geber wechselt jede Runde in Sitzreihenfolge.
